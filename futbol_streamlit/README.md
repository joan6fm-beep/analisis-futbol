# Fútbol Data Joan · V13

Esta versión mantiene el motor de Rivales de V12.2 y añade:

- Equipo → Primer Toque C.F. 'A' con J1–J5 en resultados.
- El mismo análisis base que Rivales (Total/Casa/Fuera, resultados, formaciones, XI, minutos, goles, disciplina, tramos y clasificación) cuando hay dato validado.
- Bloques preparados para tiros, tiros a puerta, posesión, córners y mapas de calor.
- Individual → desplegable de jugadores de Primer Toque y filtro por jornada.
- Estructura individual preparada para añadir métricas físicas/técnicas.

Criterio de datos: no se inventan valores. Lo pendiente se muestra vacío o como pendiente hasta validación.
